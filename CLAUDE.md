## Package Overview

`energyr` is an R data package providing Federal Energy Regulatory
Commission (FERC) datasets from 1996–2014. It exports 7 lazy-loaded
datasets: `electric`, `gas`, `oil`, `hydropower`, `lng`, `pipeline`, and
`storage`. There are no exported functions — only documented data
objects.

## Architecture

### Data layer

All datasets live in `data/*.rda` (compressed binary). Their roxygen2
documentation is in `R/<dataset>.R`. The `NAMESPACE` file is
auto-generated by roxygen2 and contains no explicit exports — datasets
are made available via lazy loading declared in `DESCRIPTION`
(`LazyData: true`).

### Documentation

- `R/energyr.R` — package-level `@docType package` stub
- `R/<dataset>.R` — one file per dataset, each containing only roxygen2
  comments (`@format`, `@source`, `@examples`)
- `man/` — auto-generated; never edit by hand

### Tests

`tests/testthat/test-<dataset>.R` — one file per dataset. Tests check:
dataset loads, correct class (`data.frame`), expected column names,
column types, dimensions, and no NAs in key fields.

### CI

- `.github/workflows/R-CMD-check.yaml` — runs `rcmdcheck` on
  macOS/Windows/Ubuntu across R devel, release, and oldrel-1
- `.github/workflows/test-coverage.yaml` — Codecov integration via
  `covr`
- `.github/workflows/pkgdown.yaml` — deploys docs to GitHub Pages

## Data Pipeline (data-raw/)

Dataset scripts live in `data-raw/`. Each script reads a source CSV from
`inst/extdata/`, processes it, and saves the `.rda` via
`usethis::use_data(overwrite = TRUE)`. Three datasets (hydropower, lng,
storage) also geocode using `tidygeocoder` with the free OSM/Nominatim
provider.

Prerequisites: `install.packages(c("here", "tidygeocoder", "usethis"))`

To regenerate all datasets:

``` r
source("data-raw/update_all.R")
```

To regenerate a single dataset:

``` r
source("data-raw/electric.R")    # or gas, oil, pipeline — no geocoding, < 5 sec
source("data-raw/lng.R")         # ~1 min  (~39 OSM geocode calls)
source("data-raw/storage.R")     # ~10 min (~223 OSM geocode calls)
source("data-raw/hydropower.R")  # ~30 min (~1030 OSM geocode calls)
```

Source CSVs must be present in `inst/extdata/` before running. See each
script’s header comment for the FERC download URL.

## Adding or Updating a Dataset

1.  Place the source CSV in `inst/extdata/<name>.csv`.
2.  Create or update `data-raw/<name>.R` following the existing script
    pattern.
3.  Run the script to produce `data/<name>.rda`.
4.  Edit `R/<name>.R` with roxygen2 `@format`, `@source`, and
    `@examples` tags.
5.  Add or update `tests/testthat/test-<name>.R` with column and type
    checks.
6.  Run `devtools::document()` then `devtools::check()`.
